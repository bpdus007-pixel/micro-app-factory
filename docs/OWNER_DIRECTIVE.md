## 0. 위임
- 기획·개발·자동화·배포·운영·개선 권한을 Claude 에게 위임. 소유자는 비개발자이며 코드 작성·명령 실행을 하지 않고, 이후 거의 관여하지 않는다.

- 꼭 필요한 승인·계정 연결이 있을 때만 요청.

## 1. 목표
- 분야 제한 없이 서로 다른 실용 기능의 초소형 웹앱 1,000개를 제작·공개.
- 가정한 수익 분포(보장 아님): 무수익 900, 월 1,000원 미만 80, 3,000~5,000원 15, 5,000~20,000원 4, 20,000~50,000원 1. 전부 무수익도 허용.
- 진짜 목적: 극히 낮은 제작·유지비로 다수의 작은 디지털 자산을 보유하고 소액 수익을 장기 누적. 무리한 투자·확대·고용·외주 금지.

## 2. 운영 원칙 (우선순위 순)
1. 사람 개입 극소화 2. 신규 고정비·유지비 극소화 3. 개발보다 실제 공개·지속 운영 4. 실제 불편 해결
5. 속도보다 자동화 안정성·결과 정확성 6. 매출 없는 앱에 관리비 발생 금지 7. 이름만 바꾼 중복 금지
8. 사용자 피해 가능 오류 발견 시 자동 격리·배포 중단. 추가 지시 없이 작업이 이어지도록 설계.

## 3. 아이디어
- 분야 자유. 초기 우선: 계산기, 변환기, 간단한 생성기, 데이터 정리, 문서 검사·편집, 간단한 시뮬레이터, 일정·수량·비용 계획, 비교·분석·의사결정 보조.
- 입력에 따라 명확히 유용한 결과. 서버·DB·회원가입·개인정보 수집·실시간 외부 API 불필요한 앱 우선.
- 의료 진단·투자 권유·법률 판단 등 고위험 제외. 독창적 효용 없는 페이지 양산·검색 순위 조작 금지. 앱마다 실질적으로 구별되는 목적·기능.

## 4. 기술
- 공통 코드베이스 + 공통 배포, 앱별 별도 URL. 권장: Claude Code, Claude Code Routines, GitHub, Cloudflare Pages, 자동 테스트, GitHub 연동 CI/CD, 간단한 대시보드.
- 더 적합한 무료 기술이면 변경 가능. 기준은 유지비·안정성·반복 생산 능력. 소유자에게 코드·명령 요구 금지.

## 5. 무인 자동 실행 (최우선 과제)
- 단일 대화 세션 유지에 의존하는 구조 금지. 실행마다 저장소 기록을 읽고 이어감.
- Claude Code Routines 우선. 최초 주기 한국시간 매일 1회, 실행당 앱 1개 → 안정 확인 후 확대.
- 실행 절차: 상태 확인 → 완료·실패·다음 작업 확인 → 아이디어 선택 → 중복·효용 검토 → 개발 → 자동 테스트 → 수정·재테스트 → 검증 통과분 배포 → 공개 URL 확인 → 상태·이력 저장 → 종료.
- 사용량 한도·장애 시 상태 유실 금지. 예약 생성·다음 실행·상태 보존을 검증. 설정 못 한 예약을 완료로 보고 금지.

## 6. 장기 기억

- 재실행 시 중복 제작 금지, 실행이 겹쳐도 중복 작업·데이터 손상 금지. 운영 지침을 CLAUDE.md 등에 기록. 저장소만으로 새 세션이 정확히 이어갈 수 있을 것.

## 7. 품질
- 작동하는 기능, 모바일·PC, 입력 오류 처리, 정확한 결과, 버튼·입력 정상, 심각한 보안 문제 없음, 불필요한 개인정보 요구 없음, 저작권·지재권 침해 없음, 기존 앱과 기능 중복 없음.
